# HashMap Electronics Inventory Management

## 1. Project Overview

A Java application that demonstrates the use of HashMap to store and manage electronics inventory using key-value pairs.

## 2. Objective

To understand how HashMap works for storing, updating, searching, and deleting data efficiently.

## 3. Features

* Add electronic products.
* Update existing product stock.
* Search for a product.
* Remove products.
* Display all inventory items.

## 4. Technologies Used

* Java
* HashMap
* Map Interface
* Java Collections Framework

## 5. Data Structure Used

HashMap<String, Integer>

* Key: Product Name
* Value: Stock Quantity

## 6. Operations Demonstrated

* put()
* get()
* containsKey()
* remove()
* entrySet()
* Enhanced for loop

## 7. Key Learning Concepts

* Key-Value Pair Storage
* Duplicate Key Handling
* Iterating Through Collections
* Inventory Management Logic

## 8. Program Workflow

1. Create a HashMap.
2. Add electronic products.
3. Update existing entries.
4. Check product availability.
5. Remove unwanted products.
6. Display final inventory.

## 10. Conclusion

This project provides a practical introduction to Java HashMap operations and demonstrates how key-value collections can be used for simple inventory management applications.
